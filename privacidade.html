Política de privacidade

Última atualização: 21 de novembro de 2026

A App Hábitos é uma aplicação pessoal para registar hábitos diários. Esta página explica que dados guarda, onde, e o que podes fazer com eles.

Que dados guardamos

  • Conta: o teu email e, se entrares com Google, o teu nome. A app nunca vê a tua palavra-passe da Google.
  • Registos: o que escreves na app: refeições, atividade física, líquidos, sono, meditação, leitura, peso, notas e resultados de consultas.
  • Definições: os teus objetivos, refeições habituais, atividades e bebidas.

Onde ficam e quem os vê

Os dados ficam numa base de dados do Supabase, alojada na União Europeia. Cada conta só consegue ler e alterar os seus próprios dados: há regras de segurança na base de dados que o garantem.

Os dados não são vendidos, partilhados com terceiros nem usados para publicidade.

Para que são usados

Apenas para te mostrar os teus registos e os resumos calculados a partir deles (por exemplo, a média de sono da semana).

Os teus direitos
